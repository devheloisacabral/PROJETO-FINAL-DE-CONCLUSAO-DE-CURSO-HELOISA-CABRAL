# P18-C — Lista de espera para turmas cheias

## Contexto

A API bloqueia matrícula quando a turma está sem vaga. Alunos ativos poderão entrar em lista de espera, e o cancelamento de matrícula deverá promover automaticamente o próximo aluno elegível.

## Objetivo

Implementar lista de espera para turmas, alterando as regras de matrícula, capacidade e cancelamento sem criar frontend, dependências novas ou funcionalidades fora desta manutenção.

## Critérios BDD

### Cenário: Aluno entra na lista de espera quando turma está cheia

Dado que existe uma turma ativa sem vagas
E existe um aluno ativo não matriculado nessa turma
Quando o administrador solicita matrícula do aluno nessa turma com aceite de lista de espera
Então o aluno deve ser incluído na lista de espera
E nenhuma matrícula ativa deve ser criada

### Cenário: Sistema impede duplicidade na lista de espera

Dado que o aluno já está na lista de espera de uma turma
Quando o administrador tenta incluir o mesmo aluno novamente
Então a API deve bloquear a operação
E a posição original deve ser preservada

### Cenário: Cancelamento de matrícula promove primeiro aluno elegível

Dado que existe uma turma cheia
E existe lista de espera com alunos elegíveis em ordem
Quando o administrador cancela uma matrícula ativa da turma
Então a primeira pessoa elegível da lista deve ser promovida para matrícula ativa
E deve sair da lista de espera

### Cenário: Aluno inelegível é pulado na promoção

Dado que o primeiro aluno da lista está inelegível
E o segundo aluno está elegível
Quando uma vaga é liberada
Então o segundo aluno deve ser promovido
E o aluno inelegível deve permanecer na lista de espera

### Cenário: Aluno matriculado não pode entrar na lista da mesma turma

Dado que o aluno já possui matrícula ativa em uma turma
Quando o administrador tenta colocá-lo na lista de espera dessa mesma turma
Então a API deve bloquear a operação

## Regras técnicas

- A solicitação utiliza `POST /matriculas` com `aceitarListaEspera`.
- A lista de espera mantém ordem por data de solicitação e identificador.
- São elegíveis alunos ativos, sem matrícula ativa na turma e sem mensalidade vencida.
- A promoção e o cancelamento ocorrem na mesma transação.
- A lista de espera deve possuir unicidade para aluno e turma enquanto a entrada estiver ativa.
