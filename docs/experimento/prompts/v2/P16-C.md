# P16-C — Cancelamento de matrícula com histórico e vaga

## Contexto

A matrícula representa vínculo ativo entre aluno e turma e impacta capacidade. Agora será possível cancelar matrícula sem apagar histórico, liberando vaga e afetando presença e consulta de aulas futuras.

## Critérios BDD

Funcionalidade: Cancelamento de matrícula

### Cenário: Administrador cancela matrícula ativa

Dado que existe uma matrícula ativa entre aluno e turma
Quando o administrador cancela a matrícula
Então a matrícula deve ficar cancelada
E a vaga da turma deve ser liberada

### Cenário: Sistema impede cancelamento de matrícula já cancelada

Dado que existe uma matrícula cancelada
Quando o administrador tenta cancelar a mesma matrícula novamente
Então a API deve bloquear a operação
E não deve alterar contadores ou histórico

### Cenário: Aluno com matrícula cancelada não recebe presença futura

Dado que existe uma matrícula cancelada para uma turma
E existe aula futura dessa turma
Quando o professor tenta registrar presença para o aluno nessa aula
Então a API deve bloquear o registro

### Cenário: Presenças antigas são preservadas

Dado que o aluno teve presença registrada antes do cancelamento da matrícula
Quando a matrícula é cancelada
Então a presença antiga deve continuar consultável no histórico

### Cenário: Nova matrícula ativa não pode duplicar vínculo ativo

Dado que já existe matrícula ativa para o aluno na turma
Quando o administrador tenta matricular o mesmo aluno novamente na mesma turma
Então a API deve bloquear duplicidade
E deve manter apenas uma matrícula ativa

## Regras

- A matrícula deve possuir status `ativa` ou `cancelada`.
- O cancelamento deve alterar o status sem apagar o registro.
- A capacidade deve contar apenas matrículas ativas.
- Deve existir no máximo uma matrícula ativa para o mesmo aluno e turma.
- O registro de presença exige matrícula ativa na turma.
- Presenças já registradas não devem ser apagadas pelo cancelamento.
- Não criar frontend, dependências novas ou funcionalidades fora desta manutenção.
