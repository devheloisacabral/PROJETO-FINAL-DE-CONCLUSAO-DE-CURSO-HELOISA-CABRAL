Você é um desenvolvedor backend Java. Sua função é desenvolver apenas as funcionalidades descritas neste prompt.

Funcionalidade: Consultar dashboard administrativo

Como administrador
Quero consultar indicadores consolidados do sistema
Para acompanhar a situação dos alunos, professores, matrículas e mensalidades

Cenário: Consultar dashboard de um mês específico

    Dado que o usuário autenticado possui o perfil "admin"
    E o mês informado é "2026-09"
    Quando enviar uma requisição GET para "/admin/dashboard?mes=2026-09"
    Então a API deve retornar HTTP 200
    E deve retornar um objeto JSON contendo mesReferencia, totalAlunos, totalProfessores, matriculasAtivas, mensalidadesPendentes e proximasAulas

Cenário: Calcular os indicadores do dashboard

    Dado que existem alunos, professores, matrículas e mensalidades do mês de referência
    Quando o dashboard for consultado
    Então totalAlunos deve representar todos os alunos cadastrados
    E totalProfessores deve representar todos os professores cadastrados
    E matriculasAtivas deve representar matrículas de alunos ativos em turmas ativas
    E mensalidadesPendentes deve representar mensalidades do mês informado com status "pendente"

Cenário: Retornar as próximas aulas

    Dado que existem aulas futuras vinculadas a turmas
    Quando o dashboard for consultado
    Então proximasAulas deve conter no máximo 5 aulas ordenadas por data, horário de início e id
    E cada aula deve conter id, data, horarioInicio, horarioFim, turmaId, turmaNome e cancelada

Cenário: Consultar dashboard sem aulas futuras

    Dado que não existem aulas futuras
    Quando o dashboard for consultado
    Então a API deve retornar HTTP 200
    E proximasAulas deve ser uma lista vazia

Cenário: Recusar consulta por usuário sem permissão

    Dado que o usuário autenticado não possui o perfil "admin"
    Quando enviar uma requisição GET para "/admin/dashboard?mes=2026-09"
    Então a API deve retornar HTTP 403

Cenário: Recusar mês em formato inválido

    Dado que o usuário autenticado possui o perfil "admin"
    Quando enviar uma requisição GET para "/admin/dashboard?mes=09-2026"
    Então a API deve retornar HTTP 400

Somente os cenários deste prompt estão autorizados para implementação. Não criar frontend, filtros, paginação pública, gráficos, exportações, novas entidades ou dependências.
