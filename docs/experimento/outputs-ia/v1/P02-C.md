Implementação do Prompt 02 concluída.

- Spring Security configurado para API stateless.
- Login implementado em `POST /auth/login`.
- Access tokens JWT assinados com RS256 e validade de 15 minutos.
- Refresh tokens opacos com validade de 7 dias.
- Refresh tokens persistidos somente como hash SHA-256.
- Rotação, expiração, reutilização e revogação implementadas.
- Logout implementado em `POST /auth/logout`.
- Consulta do usuário autenticado implementada em `GET /auth/me`.
- Autorização administrativa implementada em `POST /admin/protected`.
- Senhas verificadas com BCrypt e nunca retornadas nas respostas.
- Chave privada RSA lida exclusivamente pela configuração externa `JWT_PRIVATE_KEY`.
- Chaves RSA menores que 2048 bits são rejeitadas.
- `/health` permanece público com resposta `{"status":"operational"}`.
- Migration `V2__create_refresh_tokens_table.sql` criada para persistência segura e rotação.
