Implementação do Prompt 04 realizada dentro do escopo fechado de planos e mensalidades.

- Migration Flyway V4 criada para `plans`, `monthly_fees` e associação opcional de plano em `users`.
- Restrição de unicidade criada para aluno e mês de referência.
- Status financeiros limitados a `pendente` e `paga`.
- `POST /planos` criado para admin.
- `PUT /alunos/{id}/plano` permite associação e substituição de plano.
- Mensalidades usam o valor do plano e vencem no dia 10.
- Recebimento altera para `paga` e ativa aluno inativo na mesma transação.
- Cancelamento retorna `paga` para `pendente`.
- Consultas financeiras são autorizadas para admin e para o próprio aluno.
- Professor e aluno são impedidos de executar operações administrativas.
- Dependências de teste adicionadas para Testcontainers PostgreSQL.
