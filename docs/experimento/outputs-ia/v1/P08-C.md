Implementação do Prompt 8 realizada dentro do escopo fechado de gerenciamento de aulas.

- Migration Flyway V8 criada para `lessons`, com vínculo obrigatório à turma, horários, data, indicador de cancelamento, constraint de ordem dos horários e índices.
- `POST /aulas` permite geração somente por admin.
- A geração valida turma existente, data correspondente ao dia da turma e horários válidos, copiando os horários configurados e iniciando `cancelada` como falso.
- `GET /aulas` e `GET /aulas/{id}` aplicam autorização por perfil: admin consulta todas; professor consulta turmas associadas; aluno consulta turmas em que está matriculado.
- Aulas canceladas permanecem consultáveis por usuários autorizados.
- Respostas de erro foram adicionadas para recurso inexistente, data incompatível, dados inválidos e acesso negado.
- Nenhuma senha, token, credencial ou dado sensível foi registrado na documentação.
