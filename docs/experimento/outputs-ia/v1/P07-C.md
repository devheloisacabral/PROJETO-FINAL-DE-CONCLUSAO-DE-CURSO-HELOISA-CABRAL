Implementação do Prompt 07 realizada dentro do escopo fechado de matrículas.

- Migration Flyway V7 criada para `enrollments`, com chaves estrangeiras, índices e unicidade da relação aluno/turma.
- `POST /matriculas` cria matrícula somente para admin, aluno ativo, turma ativa e capacidade disponível.
- A matrícula registra `enrolledAt` e não possui campo de status.
- `GET /matriculas` retorna todas as matrículas para admin e somente as do aluno autenticado para aluno.
- A turma é bloqueada com lock pessimista durante a verificação de capacidade e criação.
- Respostas usam DTOs sem senha, hash, token ou dados sensíveis internos.
- A V7 amplia evolutivamente o constraint de status dos usuários para permitir `ativo` e `inativo`, sem alterar a V3.
