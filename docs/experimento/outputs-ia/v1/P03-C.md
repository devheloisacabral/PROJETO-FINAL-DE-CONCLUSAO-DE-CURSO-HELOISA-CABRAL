Implementação do Prompt 03 concluída dentro do escopo de cadastro e consulta de alunos.

- Migration Flyway V3 adicionada para nome, telefone, data de nascimento e status.
- `POST /alunos` criado para administradores autenticados.
- Alunos são criados com perfil `aluno` e status `inativo` definido pelo servidor.
- E-mail normalizado e protegido por unicidade existente na tabela `users`.
- Senha persistida somente com `PasswordEncoder`/BCrypt.
- Campo `status` enviado no JSON é rejeitado como propriedade desconhecida.
- `GET /alunos` retorna todos para admin e somente o próprio cadastro para aluno.
- Professor não recebe consulta indiscriminada sem relação autorizada disponível neste escopo.
- Respostas de aluno não expõem a senha.
- Tratamento de e-mail duplicado retorna HTTP 409.
