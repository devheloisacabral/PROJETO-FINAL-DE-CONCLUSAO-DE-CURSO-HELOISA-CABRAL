# Implementação do Prompt 10 — Dashboard administrativo

A implementação adicionou o endpoint `GET /admin/dashboard?mes=yyyy-MM`, restrito ao perfil `admin` pela regra existente de `/admin/**`.

## Principais alterações

- Criado `DashboardService` para validar o mês e consolidar os indicadores.
- Criado `AdminDashboardController`.
- Adicionadas queries para contar alunos, matrículas ativas e mensalidades pendentes.
- Adicionada consulta de próximas aulas futuras, ordenada e limitada internamente a cinco registros.
- Adicionado tratamento HTTP 400 para mês inválido.
- Não foi criada migration nem dependência nova; o schema V1–V9 existente já contém as entidades necessárias.

## Contrato retornado

O JSON contém `mesReferencia`, `totalAlunos`, `totalProfessores`, `matriculasAtivas`, `mensalidadesPendentes` e `proximasAulas`. Cada próxima aula contém `id`, `data`, `horarioInicio`, `horarioFim`, `turmaId`, `turmaNome` e `cancelada`.

## Validação

Os testes focados e a suíte Maven passaram. O empacotamento Maven passou e `git diff --check` não encontrou problemas. Docker não estava disponível; portanto, a validação com PostgreSQL/Testcontainers, Flyway em banco real, processo HTTP real, `/health` HTTP real e SonarQube permaneceram pendentes.

Nenhuma senha, chave privada, token ou credencial foi incluída nos arquivos.
