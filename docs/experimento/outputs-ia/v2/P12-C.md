# Implementação do P12-C — Bloqueio operacional por inadimplência

A implementação passou a consultar mensalidades pendentes vencidas antes de permitir matrícula ou registro de presença.

## Principais alterações

- Adicionado no repositório de mensalidades o método para verificar pendência vencida por aluno.
- Matrículas são bloqueadas antes da contagem de vagas e da persistência quando há inadimplência.
- Presenças são bloqueadas antes da persistência quando há inadimplência.
- Adicionada resposta HTTP `409` com erro `student_in_debt`.
- Pagamento existente continua alterando a mensalidade para `paga`, removendo o resultado da consulta de bloqueio.

Não foram adicionadas dependências, endpoints novos, credenciais ou dados sensíveis.
