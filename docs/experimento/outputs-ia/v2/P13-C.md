# Implementação do P13-C — Troca de plano com vigência

A associação direta de plano foi evoluída para uma associação histórica por aluno e data inicial de vigência.

## Principais alterações

- Criada a entidade `PlanAssignment` e o repositório de histórico de planos.
- Criada a migration `V11__create_student_plan_history.sql`, com chave estrangeira, índice e unicidade por aluno e data de início.
- O endpoint `PUT /alunos/{id}/plano` passou a receber `planId` e `validFrom`.
- Mensalidades passaram a consultar o plano vigente no mês de referência.
- O valor salvo na mensalidade continua independente de alterações posteriores no plano.
- Trocas duplicadas retornam `409` com `plan_change_already_exists`.
- A associação legada do serviço foi preservada para compatibilidade interna.

Não foram adicionadas dependências, credenciais, tokens ou dados sensíveis.
